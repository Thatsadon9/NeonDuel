> เป้าหมาย: เกมต้อง **สนุกและท้าทายพร้อมกัน** — ชนะเพราะอ่านท่า Parry/Dash ถูกจังหวะ และใช้สกิลถูกเวลา

## 1. ต้นเหตุ (เรียงตามความรุนแรง)

### A. Focus ไม่เคยหมด (ต้นเหตุใหญ่ที่สุด)
- **สกิลที่โดนศัตรูคืน Focus เอง** — ทุกฮิตของสกิลได้ Focus 1.2 × (ดาเมจ/14, สูงสุด ×2.2) ≈ **2.6 ต่อฮิตต่อศัตรู** + ฆ่าได้ +8
  → Phantom Slash (35 Focus) ฟาดกลุ่ม 5 ตัว ได้คืน ~40 = **ฟรีและกำไร**
- **Last Harvest (Scythe T4) ตั้ง Focus = 100 หลังใช้** → กด Ultimate ได้ไม่รู้จบ และกิน HP บอส 10% ต่อครั้ง (**บั๊กลูปที่แรงที่สุด**)
- **Iron Guard (Gauntlets Q)** Parry อัตโนมัติทุกอย่าง 1.5 วิ แต่ละ Parry ได้ Focus +25 → เจอกระสุนเยอะ = Focus เต็มทันที + อมตะต่อเนื่อง
- ดวงวิญญาณ (Scythe Harvest) ได้ Focus +3 และ HP +2 ต่อดวง · Death Mark พลาดได้คืน 22 · Execute ได้ +30
- ไม่มี cooldown ของสกิลเลย — มีแค่ Focus

### B. อมตะมากเกินไป
| แหล่ง | อมตะ |
|---|---|
| Phantom Slash (Katana Q) | **1.2 วิ** + เวลาช้าลงทั้งจอ |
| Death Mark (Daggers E) | 1.0 วิ |
| Thunderclap Step (Raijin E) | 0.9 วิ |
| Gale Rush (Tempest E) | 1.0 วิ |
| Thousand Gale (Ultimate) | 1.5 วิ |
| Iron Guard | Parry ทุกอย่าง 1.5 วิ |
| Dash | 0.2 วิ ทุกครั้ง · ไม่ใช้ Stamina |

### C. Dash / Perfect Dodge เป็นวงจรอมตะ
- Perfect Dodge **คืน Dash 1 ครั้ง** + อมตะเพิ่ม 0.25 วิ + Focus +16 + เวลาช้าลง
- เจอกระสุนรัว (Hex Weaver) → ทุก Dash ชนกระสุน = Perfect ทุกครั้ง = **Dash ไม่มีวันหมด**
- กระสุนที่ชนตอนอมตะ "ทะลุผ่าน" → Dash เข้าใส่ม่านกระสุนได้ฟรี
- Lightbow: Dash ทุกครั้งเติมลูกศรพลัง 3 ดอก → Dash สแปม = ยิงพลังไม่หยุด

### D. ตัวเลขฝั่งเรา vs ฝั่งศัตรู
- HP บอส 540–2,600 ขณะที่ดาเมจเราคูณซ้อนกันได้: Tier ×1.75 · Keen Edge ×1.15³ · Glass ×1.35 · Momentum +30% · Overdrive ×1.25 · คริ ×1.8
- Execute บอส = **12% ของ HP สูงสุด** + ดาเมจ (มีการ์ดคูณ ×1.6 อีก)
- ศัตรูลูกน้อง HP 10–220 → สกิล AoE ลบทั้งจอในทีเดียว
- การฟื้น HP เยอะ: Overdrive +15% · ผ่านด่าน +20% · การ์ด Mend +60% (ซ้อนได้ 99) · Reaper +4/kill · วิญญาณ Scythe

### E. อื่น ๆ ที่พบเพิ่ม (ผู้ใช้ยังไม่ได้บอก)
1. **เวลาช้าลง (slow-mo) เกิดบ่อยมาก** (Parry, Perfect, Overdrive, Phantom, Execute, Stagger) → ศัตรูช้าลงเกินครึ่งเวลา ทำให้เกมง่ายและเสียจังหวะ
2. **Phantom Slash ล็อกเป้าอัตโนมัติไกล 650** — ไม่ต้องเล็ง ไม่มีความเสี่ยง
3. **Blade Storm (Katana E)** ลบกระสุนรอบตัว 3.5 วิ → บอสยิงกระสุน (Hex, Tempus, Hollow) ไร้ผล
4. **Singularity passive** กระสุนใกล้ตัวช้าลง 50% ตลอดเวลา
5. **Eclipse (Yami ult)** หยุดเวลาศัตรู 2.4 วิ + ดาเมจซ้ำ 60%
6. **Hollow King ตกเหวเสีย 15% ของ HP สูงสุด** — ไม่ใช่ปัญหาความง่าย แต่ควรเป็นค่าคงที่ (ป้องกันบั๊กกับ HP สูง ๆ)
7. **Endless:** การ์ดซ้อนได้ไม่จำกัด (Power Surge +8% ต่อใบ) โตแบบทวีคูณ แซงความยากที่โตแบบเส้นตรง
8. **Co-op:** HP บอสเพิ่ม +65%/คน แต่ดาเมจรวม 2 คนเกิน 2 เท่าเพราะสกิลซ้อน — ควรเพิ่มเป็น +90%/คน

## 2. หลักออกแบบใหม่

1. **Focus = รางวัลของการเล่นเก่ง** ได้จาก Parry, Perfect Dodge และตีธรรมดาให้โดน — **ไม่ใช่ได้จากสกิล**
2. **สกิล = ไพ่ตาย** ใช้ได้ทุก ~5–10 วิ ไม่ใช่ทุก 0.5 วิ
3. **อมตะ = สั้นและต้องจับจังหวะ** ไม่มีสกิลไหนอมตะเกิน 0.4 วิ ยกเว้น Ultimate
4. **Dash = เครื่องมือหลบ ไม่ใช่โล่** มีต้นทุน (Stamina) ถ้า Dash พร่ำเพรื่อจะหมดแรง
5. **บอส = ข้อสอบ** ช่วง "โจมตีได้จริง" คือตอน Parry แล้วบอสเสียหลัก หรือหลังบอสใช้ท่าใหญ่ (punish window)

### เป้าหมายตัวเลข (วัดด้วยบอทชุดเดิมหลังปรับ)
| ตัวชี้วัด | ตอนนี้ | เป้าหมาย |
|---|---|---|
| บอส Act I (บอทสแปม, Tier ตามด่าน) | 4–13 วิ | **45–75 วิ** |
| บอส Act II / Hollow King (T4) | 3.5–17 วิ | **90–150 วิ** |
| สกิลที่ใช้ได้ต่อนาที | 100–200 | **8–15** |
| Dash สแปม: ลดดาเมจที่โดนเทียบกับยืนเฉย | ~50% | **≤ 20%** (หลบเก่งต้องจับจังหวะ ไม่ใช่กดรัว) |
| บอทตีอย่างเดียว ไม่หลบ | รอดบอส 2 | **ตายก่อนชนะบอส 2–3** |

### 3.6 เพิ่ม "ความท้าทาย" ไม่ใช่แค่เพิ่ม HP
1. **ลด slow-mo:** รวมเวลาสโลว์ต่อ 10 วิไม่เกิน ~1 วิ · Parry 0.4 → 0.25 วิ · Stagger 0.45 → 0.3
2. **บอสลงโทษการสแปม:** ถ้าผู้เล่นใช้สกิล 2 ครั้งภายใน 3 วิ บอสเข้า **Super Armor** 2 วิ (ไม่เสียหลัก/ไม่ชะงัก) — บอกด้วยออร่าขาว
3. **Punish window ชัดเจน:** หลังท่าใหญ่บอสค้าง 0.8–1.2 วิ (มีอยู่แล้วบางตัว ทำให้ครบทุกตัว) → รางวัลของการหลบถูก
4. **ลูกน้องรุมเป็นทีม:** Rusher/Lancer รอจังหวะพร้อมกัน, Gunner ยิงสลับ → ต้องจัดตำแหน่ง
5. **Act II ดาเมจศัตรู ×1.2** (Act I คงเดิม เพราะเป็นช่วงเรียนรู้)
6. **Hollow King ตกเหว** = 15 ดาเมจคงที่ (แทน 15%)
7. **Co-op:** HP บอส +90% ต่อผู้เล่นที่เพิ่ม (จาก 65%)

## 5. ที่ต้องให้ผู้ใช้ตัดสินใจ
1. **ระดับความยาก NORMAL ใหม่** — ยากระดับ "ต้องตายสัก 2–3 ครั้งกว่าจะผ่าน Act I" ใช่ไหม หรือโหดกว่านี้
2. **โหมดง่ายสำหรับคนทั่วไป** — ควรเพิ่ม STORY (ใช้ค่าเดิมก่อนปรับ) ไว้ด้วยไหม
3. **Cooldown บนสกิล** — โอเคกับการมีทั้ง Focus และ Cooldown ไหม หรืออยากให้เป็น Focus อย่างเดียวแต่แพงขึ้นมาก
4. **Stamina ของ Dash** — ใช้ร่วมกับ Block (ต้องเลือกว่าจะกันหรือหลบ) หรือแยกแถบ
