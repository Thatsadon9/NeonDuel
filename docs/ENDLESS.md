# ENDLESS MODE — ออกแบบและความพร้อมของระบบ

## 1. ออกแบบโหมด

**เป้าหมาย:** อยู่รอดให้นานที่สุด รอบละ 1–2 นาที ศัตรูแกร่งขึ้นทุกรอบ สู้จนตาย
คะแนนวัดจากจำนวนรอบที่รอดเป็นหลัก

### โครงสร้างรอบ
| รอบ | เนื้อหา |
|---|---|
| ปกติ | คลื่นศัตรูสุ่มตาม "งบ" ที่โตตามรอบ: 2–4 คลื่นย่อย, คลื่นละไม่เกิน 14 ตัว (คุมทั้งความแฟร์และ performance) |
| ทุก 5 รอบ | บอส 1 ตัวแบบสุ่ม ไม่ซ้ำกับบอสครั้งก่อน |
| ทุก 10 รอบ | **GAUNTLET**: สองบอสพร้อมกัน (HP คนละ 70%) |
| ปลดล็อกศัตรู | Rusher / Gunner ตั้งแต่รอบ 1 · Bulwark รอบ 3 · Bomber รอบ 4 |

### ความยาก (`endlessScale` ใน `src/game/run.ts`)
| ค่า | สูตร | รอบ 10 | รอบ 20 | รอบ 40 |
|---|---|---|---|---|
| HP ศัตรู | 1 + 0.085r + 0.0025r² | ×1.97 | ×3.52 | ×8.12 |
| ดาเมจ | 1 + 0.04r (สูงสุด ×2.5) | ×1.36 | ×1.76 | ×2.5 |
| ความเร็ว | 1 + 0.01r (สูงสุด ×1.3) | ×1.09 | ×1.19 | ×1.3 |

(r = รอบ − 1)
- ความเร็วมีเพดาน เพื่อให้สัญญาณเตือน (telegraph) ยังอ่านทันและ Parry ได้เสมอ
- Posture ของบอสโตตามรากที่สองของ HP ท่า Execute จึงยังเกิดได้

### Affix (ตัวปรับรอบ)
รอบ 6–15 มี 1 อย่าง · รอบ 16–29 มี 2 อย่าง · รอบ 30 ขึ้นไปมี 3 อย่าง

| Affix | ผล |
|---|---|
| VOLATILE | ศัตรูระเบิดเป็นวงแดงหลังตาย 0.7 วินาที |
| ARMORED | ศัตรูรับดาเมจลดลง 20% |
| SWIFT | ศัตรูทั่วไปเร็วขึ้น 20% |
| FRENZIED | บอสพักระหว่างท่าสั้นลง 45% |
| VAMPIRIC | ศัตรูที่ตีโดนฟื้น HP 6% |

### การเติบโตของผู้เล่น
- **การ์ด:** เลือก 1 ใน 3 ทุกรอบ หลังบอสจะได้การ์ดระดับ rare ขึ้นไป
- **การ์ดสาย Endless:** 6 ใบที่ซ้อนได้ไม่จำกัด (Power Surge, Vitality, Deep Focus, Breaker, Haste, Precision) ทำให้การ์ดไม่มีวันหมด
- **อาวุธ:** การ์ดปลดล็อกอาวุธการันตีในรอบ 1 และทุก 7 รอบ
- **ฟื้น HP:** 15% หลังคลื่นศัตรู และ 35% หลังบอส

### คะแนนและ leaderboard
- **สูตร:** `รอบ×1200 + รอบ²×25 + คะแนนต่อสู้` (Hard ×1.5) คำนวณฝั่งเซิร์ฟเวอร์
- **Leaderboard:** แยก CAMPAIGN / ENDLESS × NORMAL / HARD
- **รอบซ้อม:** รอบที่เริ่มกลางทาง (`?mode=endless&stage=N`) ไม่ถูกบันทึก

## 2. ระบบตอนนี้พร้อมหรือยัง?

### ✅ ที่ทำเพิ่มในรอบนี้ (เดิมยังไม่พร้อม)
| ระบบ | ปัญหาเดิม | ที่แก้ |
|---|---|---|
| Run controller | ผูกกับ 10 ด่านตายตัว | รองรับหลายโหมด + สร้างรอบแบบ procedural |
| ศัตรู / บอส | ไม่มีการปรับความยากนอกจาก Hard | มีตัวคูณ HP / ดาเมจ / ความเร็ว / Posture ทุกตัว |
| คลื่นศัตรู | เขียนมือ 5 ชุด | สร้างจากงบ + จำกัดจำนวนพร้อมกัน |
| การ์ดอัปเกรด | ~28 ใบ ส่วนใหญ่เลือกได้ครั้งเดียว — หมดในราว 40 รอบ | การ์ดซ้อนไม่จำกัด + การ์ด rare หลังบอส |
| ความหลากหลาย | ไม่มี | Affix 5 แบบ + Gauntlet สองบอส |
| Leaderboard | ฐานข้อมูลรับได้แค่ด่าน 0–10 | migration `002_endless_mode.sql` + แยกตาม mode |

### ⚠️ ยังขาด (เรียงตามผลต่อความสนุกระยะยาว)
1. **ความหลากหลายของเนื้อหา** — บอส 5 ตัวและศัตรู 4 แบบจะเริ่มซ้ำราวรอบ 20–30
   - ต้องการบอสเพิ่ม 2–3 ตัว, ศัตรูชั้นสูง (elite / ตัวยิงเลเซอร์ / ตัวเรียกลูกน้อง) และท่าเฟส 3 สำหรับรอบลึก
2. **อาวุธตันตั้งแต่กลางเกม** — มี 3 แบบ ปลดล็อกครบเร็ว ไม่มีอะไรให้ไล่ต่อ
   - ควรเพิ่ม **Weapon Evolution**: เช่นใช้อาวุธครบ X ครั้งแล้วเลือกสายพัฒนา หรือการ์ด legendary เฉพาะอาวุธ
3. **สกิลไม่มีสายพัฒนา** — มีแค่ 2 สกิลต่ออาวุธ และใช้ Focus อย่างเดียว
   - ควรมี **Skill Augment** เช่น Phantom Slash ฟันเพิ่มเป็น 5 ครั้ง หรือ Gravity Well ดูดกระสุนแล้วยิงคืน
4. **สมดุลยังไม่ผ่านการเล่นจริง** — สูตรความยากตั้งจากการคำนวณและบอทจำลอง
   - ถ้าเลือกการ์ดแบบสุ่ม ศัตรูจะแกร่งเร็วกว่าผู้เล่นตั้งแต่ราวรอบ 25 ต้องให้คนเล่นจริงหาจุดที่ "ยากแต่ยุติธรรม"
5. **Meta progression** — ตายแล้วไม่มีอะไรติดตัว ควรมีของปลดล็อกถาวร เช่นสกินหรืออาวุธเริ่มต้นใหม่
6. **สนามเดียว** — ทุกรอบใช้สนามเดิม ควรมีสนามหรือ hazard ต่อช่วงรอบ เช่นรอบ 20+ พื้นลาวาแคบลง
7. **ระบบป้องกันการโกงคะแนน** — ตอนนี้แค่ตรวจช่วงค่าและจำกัดความถี่ แบบจริงจังต้องส่ง replay หรือ seed ให้เซิร์ฟเวอร์ตรวจ
